# UzAssets IFRS qo'llanmasi

UzAssets IFRS saytining oddiy tildagi qo'llanmasi: sayt nima qiladi, qaysi sahifa nima uchun, kirim-chiqim qanday hisoblanadi, 1-shakl va 2-shakl, IFRS ga mosligi va dasturchilar uchun yo'l xaritasi.

## Ochish

- Kompyuterda: `index.html` faylini ikki marta bosing, brauzerda ochiladi.
- Internetda: Vercel ga joylangan manzil orqali.

Bu bitta statik HTML fayl, hech narsa o'rnatish shart emas.
